# Contributing

Issues, focused fixes and useful test cases are welcome. Describe the observed problem and how to reproduce it. Keep examples small and free of credentials or customer data.

Run the Python and browser-monitor tests before opening a pull request. Include browser tests for interface changes and meaningful regression tests for repairs or security boundaries. Do not weaken a check to make a failing proposal pass.

Keep documentation precise about what is implemented and what needs an external service or platform toolchain. Avoid claims that any model or scanner finds every bug.

Contributions are submitted under the repository's Apache 2.0 licence. Preserve existing notices and attribution.

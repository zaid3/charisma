Connect a website to Charisma +

Run the Charisma server, allow your website’s exact origin, and add its monitor script to your page. Use a fixed page label without visitor information.

<script defer src="https://YOUR-MONITOR/monitor.js"
  data-endpoint="https://YOUR-MONITOR/ingest"
  data-site-key="YOUR_PUBLIC_SITE_KEY"
  data-page="checkout"></script>

The site key is public. Keep the dashboard access token on your server. Read the setup guide ↗
